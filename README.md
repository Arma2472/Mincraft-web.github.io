# EaglercraftX Web Client (Personnalisé)

Ce dépôt contient une version personnalisée du client web EaglercraftX 1.8.8, hébergée via GitHub Pages.

## 🛠️ À propos de ce projet
Dans le cadre de nos tests et de notre démarche d'amélioration, nous avons réalisé une copie de certains fichiers clés du client d'origine (`index.html`, `classes.js`, `assets.epk`). L'objectif est d'explorer le code, de modifier l'interface ou les paramètres de base, et d'optimiser le fonctionnement du jeu directement depuis un navigateur web, sans nécessiter d'installation de logiciels lourds.

## 🚀 Utilisation
* Le site est configuré pour tourner de manière statique via **GitHub Pages**.
* Pour jouer en multijoueur, le client se connecte à des adresses WebSocket (`wss://`) compatibles configurées dans le projet.
