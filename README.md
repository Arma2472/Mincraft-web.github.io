# EaglercraftX Web Client (Personnalisé)

Ce dépôt contient une version personnalisée et optimisée du client web EaglercraftX 1.8.8, hébergée via GitHub Pages.

## 🛠️ À propos du projet
Pour concevoir et faire fonctionner ce client, nous avons utilisé et copié des fichiers de base essentiels de "https://minecraftweb.pages.dev/" (`index.html`, `classes.js`, `assets.epk`). Ces fichiers ont été ajustés et modifiés dans le but d'explorer le code, d'améliorer les performances et de tester des configurations personnalisées directement depuis un navigateur web.

## 🚀 Utilisation
* Le site est entièrement statique et fonctionne via **GitHub Pages**.
* Pour rejoindre des parties en ligne, le client se connecte à des adresses WebSocket (`wss://`) compatibles configurées dans le projet.
